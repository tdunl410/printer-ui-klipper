# Mockups

Open any page in a browser to view portrait mockups for the 7.9" touchscreen concept.

## Pages
- `index.html` — Dashboard / Workbench
- `print.html` — Active print controls + tuning
- `files.html` — File browser / model library
- `move.html` — Printer movement, homing, fan controls
- `preheat.html` — Preheat + all temperature sensors (including chamber setpoint)
- `extrude.html` — Extrusion/load/unload controls
- `control.html` — Macros + console
- `settings.html` — Navigation hub + system/theme settings
- `connectivity.html` — Moonraker + Wi-Fi/Ethernet settings
- `updates.html` — Core versions, update queue, logs/recovery

## Navigation Model
- All primary page navigation is accessed from the top-right `Settings` button.
- Bottom tabs are intentionally removed for this revision.

## Hero Render Asset
Place your provided render image at:
- `assets/printer-render.png`

The mockups are already wired to this path.

## Quick Preview
From the workspace root, run a local static server and open `mockups/index.html`.
